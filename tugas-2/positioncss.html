position static

position static digunakan untuk mengatur element menjadi statis secara default. element akan mengikuti posisi normal secara default, elemen tidak dipanggil oleh properti seperti top, bottom, left, dan right

elemen ini diatur dengan posisi static




position relative

sebuah elemen html yang menggunakan posisi relative akan terletak pada posisi normal. mengatur properti atas, kanan, bawah, kiri dari elemen yang diposisikan dengan "relatif" akan membuatnya jauh dari posisi normalnya. konten lain tidak akan disesuaikan agar sesuai dengan celah yang ditinggalkan elemen tersebut.

elemen ini diatur dengan posisi relative




position fixed

sebuah elemen html yang diatur menggunakan posisi fixed akan memiliki sifat tetap, tanpa ada perubahan bahkan jika halaman di scroll. berlaku pengaturan left, top, right, bottom

elemen ini diatur dengan posisi fixed




position absolute

elemen html yang diatur menggunakan posisi absolut akan diposisikan relatif dengan elemen lain yang mendahuluinya yang terdekat, bukan relatif terhadap layar secara normal

elemen ini diatur dengan posisi absoute
